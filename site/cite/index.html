How to cite this work

These records have no DOI. A DOI exists only after a deposit, and I have not made one. When I do, it will appear here and not before.

The dataset #

@misc{caceres2026trcs,
  author       = {Caceres, Cisco},
  title        = {{TRCS}: a synthetic radio-channel benchmark for speech recognition},
  year         = {2026},
  howpublished = {Dataset, Hugging Face},
  url          = {https://huggingface.co/datasets/RoamingPigs/trcs-tactical-audio},
  note         = {Self-published, not peer reviewed. Manifest generated 2026-10-10T21:33:12Z.}
}

A single number #

Cite the record and its run date, not only the page. For example: “Caceres, RoamingPigs Research Notes, record radio-audio, run 2026-10-10 18:34 UTC, https://roamingpigs.org/#radio-audio”. Say which evidence class applies. A simulated figure and a measured one are not the same kind of claim.

The corrections log lists every change to a published figure. The results files can be cited by URL and SHA-256.
