Check a figure #

The first record says corpus word error was {{ v.v2.w['clean'].p }}% on clean audio and {{ v.v2.w['0 dB'].p }}% at 0 dB. This recomputes those figures from the published per-clip transcripts, without any model. It needs only Python.

# corpus word error by noise level, pooled over all models and audio paths
curl -sO https://roamingpigs.org/results/trcs-full-grid-e2-per-clip.jsonl
python3 - <<'PY'
import json
rows = [json.loads(l) for l in open("trcs-full-grid-e2-per-clip.jsonl")]
for snr in [None, 20.0, 10.0, 0.0]:
    r = [x for x in rows if x["snr_db"] == snr]
    print(snr, round(sum(x["norm"]["edits"] for x in r) / sum(x["norm"]["n"] for x in r) * 100, 1))
PY

A power/rate estimate can be reproduced arithmetically: in the energy file, divide wall_power_mean_watts by tokens_per_sec for each entry in live_multi_model_sweep. This ratio is distinct from the recorded joules_per_token, which reports integrated energy over a sampling window. That window cannot be reconciled without raw traces.

What was removed #

Product names of models are replaced by size and kind, for example “39M English-only”. Local file paths, machine addresses and host names are removed. The export checks that no number changed: the sorted list of every number in each file is identical before and after. It also fails if a product name or a path is left in.

What is not here yet #

  • Model names in these files. They are replaced by size and kind on this site. The scripts and the names are on GitHub so you can re-run the exact models. See how to reproduce.
  • Scripts for the energy, agent and verifier records. The speech experiments are fully public. The code behind the other three records is not published yet.
  • The audio. It is on the dataset page. Note that the speech-model run scored a different set of utterances from the released files.
