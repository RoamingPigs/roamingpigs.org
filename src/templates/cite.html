How to cite this work

A single number #

Cite the record and its run date, not only the page. For example: “Caceres, RoamingPigs Research Notes, record radio-audio, run {{ v.e2_date }}, https://roamingpigs.org/#radio-audio”. Say which evidence class applies. A simulated figure and a measured one are not the same kind of claim.

The corrections log lists every change to a published figure. The results files can be cited by URL and SHA-256.
